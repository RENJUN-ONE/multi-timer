# ⏱ 多计时器应用

一个功能强大的多计时器网页应用，支持同时运行多个计时器，具有搜索、预警和到时提醒功能。

## ✨ 功能特性

### 🎯 核心功能
- **多计时器同时运行**：可以添加多个计时器同时计时
- **实时搜索**：根据计时器名称快速搜索和过滤
- **三列显示**：
  - 📊 **正在计时**：剩余时间大于提醒时间的计时器
  - ⚠️ **即将到时**：剩余时间小于等于提醒时间的计时器
  - ✅ **已到时**：已经到达目标时间的计时器

### ⚙️ 可配置选项
- **目标时间**：设置计时器的目标时间（分:秒）
- **提前提醒**：设置提前多少时间进入"即将到时"状态（精确到秒）
- **声音提示**：开关提示音功能

### 🎨 视觉特性
- **深色主题**：现代化的深色UI设计
- **响应式布局**：支持各种屏幕尺寸
- **动态样式**：
  - 正在计时：蓝色主题
  - 即将到时：橙色主题（带边框和阴影）
  - 已到时：绿色主题（带脉冲动画）

### 💾 数据持久化
- **本地存储**：所有计时器状态自动保存到浏览器本地存储
- **页面刷新恢复**：刷新页面后自动恢复所有计时器状态
- **运行时间补偿**：页面关闭期间的时间会被正确计算

## 🚀 快速开始

### 本地运行
1. 克隆仓库：
   ```bash
   git clone https://github.com/RENJUN-ONE/multi-timer.git
   ```

2. 进入项目目录：
   ```bash
   cd multi-timer
   ```

3. 启动本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8080
   
   # 或使用Node.js
   npx serve .
   ```

4. 在浏览器中访问：`http://localhost:8080`

### 直接使用
直接打开 `index.html` 文件即可在浏览器中使用。

## 📖 使用说明

### 添加计时器
1. 设置目标时间（分和秒）
2. 点击「+ 添加计时器」按钮
3. 计时器会自动添加到"正在计时"列

### 搜索计时器
1. 在搜索框中输入计时器名称
2. 实时显示匹配的计时器
3. 支持模糊搜索和大小写不敏感

### 设置提前提醒
1. 设置提前提醒时间（分和秒）
2. 当计时器剩余时间小于等于设置的时间时
3. 计时器会自动移动到"即将到时"列

### 计时器操作
- **开始/暂停**：控制计时器的运行状态
- **重置**：将计时器重置为初始状态
- **删除**：移除计时器
- **重命名**：点击计时器名称标签进行重命名

### 全局操作
- **全部重置**：重置所有计时器（需要二次确认）
- **声音开关**：控制提示音的开启/关闭

## 🎯 主要特性详解

### 智能排序
- **正在计时**：按剩余时间升序排列（剩余时间少的在前）
- **即将到时**：按剩余时间升序排列
- **已到时**：按到达时间升序排列（先到达的在前）

### 响应式设计
- **桌面端**：三列并排显示
- **平板端**：两列显示，自动换行
- **移动端**：单列显示，垂直排列

### 无障碍支持
- **ARIA标签**：支持屏幕阅读器
- **键盘导航**：支持键盘操作
- **减少动画**：支持用户的减少动画偏好

## 🔧 自定义配置

### 修改默认值
在 `index.html` 中修改以下变量：
```javascript
let targetSeconds = 60;     // 默认目标时间（秒）
let warningSeconds = 30;    // 默认提前提醒时间（秒）
let soundOn = true;         // 默认声音开关
```

### 修改样式
在 `<style>` 标签中修改CSS变量：
```css
:root {
  --bg: #0f1117;           /* 背景颜色 */
  --card: #1a1d27;         /* 卡片背景 */
  --accent: #5b8df9;       /* 主题颜色 */
  --danger: #f55;          /* 危险颜色 */
  --success: #4cdf8b;      /* 成功颜色 */
}
```

## 🐛 已知问题

- 在某些浏览器中，语音提示可能需要用户交互才能启用
- 页面关闭后重新打开，运行中的计时器会继续计时
- 本地存储有容量限制，过多计时器可能导致数据丢失
